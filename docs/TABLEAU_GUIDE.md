# Tableau connection

Recommended source: PostgreSQL at `localhost:5433`, database `novamart`, schema `marts`.

Build five dashboard pages:
1. Executive Overview — revenue, margin, orders, AOV, customers.
2. Sales Performance — month, country, channel, category and store.
3. Customer Analytics — loyalty tiers, cohorts and repeat purchase.
4. Marketing — spend, CPC and attributed revenue assumptions.
5. Data Quality — duplicates, rejected quantities, missing cities and reconciliation flags.

Use a blue/teal executive theme, EUR currency formatting and a global date/country filter.
